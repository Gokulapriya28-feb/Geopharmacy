# 💊 Geopharmacy

**Geopharmacy** is a responsive web-based pharmacy management system designed to help users search medicines, view medicine details, and access healthcare information through a simple and user-friendly interface. The project is built using HTML, CSS, and JavaScript.

## 📌 About the Project

Geopharmacy is a responsive web application that helps users search medicines, view medicine details, and access pharmacy-related information through a simple and user-friendly interface. It is developed using HTML, CSS, and JavaScript.

- 🔍 Search medicines quickly
- 💊 View medicine details

- 🎨 Simple and attractive design
